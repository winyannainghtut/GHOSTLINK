Mesh

A private network between your Linux servers.

Connect your servers privately

Every Linux server you add gets a private address (100.96.x.x by default) and reaches the others directly over WireGuard, or through a relay when it is behind NAT. This server coordinates the mesh; you see it here as a live map. Windows servers and the Ghostlink app as a node will follow in a later version.

Monitoring

Off by default. When on, the server keeps per-user totals per service (for example "YouTube 4 GB"), never a timestamped list of pages, and deletes them after the retention below. Turning it off deletes every recorded site at once.

Keys

Share a key only with the person it belongs to.

A shared group key is weak: everyone with the group key can pretend to be this server to other IPsec users, and its handshake can be guessed offline. Prefer a certificate or IKEv2.

The device installs these with a profile (.mobileconfig) and keeps the password or certificate in its Keychain. A different remote identifier is added to the server certificate.

Add a node

Creates an invite and one command to run on the Linux server you want to add (Ubuntu, Debian, Fedora, RHEL and similar, with kernel WireGuard).

Access rules

One rule per line: FROM TO PROTOCOL [PORTS], where FROM and TO are *, tag:NAME or node:NAME, the protocol is tcp, udp, icmp or any, and ports look like 5432 or 8000-8100. With no rules, every node reaches every node; with rules, only matching traffic passes (replies always do).
