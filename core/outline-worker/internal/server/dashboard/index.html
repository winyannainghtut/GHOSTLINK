Off by default. When on, the server keeps per-user totals per service (for example "YouTube 4 GB"), never a timestamped list of pages, and deletes them after the retention below. Turning it off deletes every recorded site at once.

Keys

Share a key only with the person it belongs to.

A shared group key is weak: everyone with the group key can pretend to be this server to other IPsec users, and its handshake can be guessed offline. Prefer a certificate or IKEv2.

The device installs these with a profile (.mobileconfig) and keeps the password or certificate in its Keychain. A different remote identifier is added to the server certificate.
