# Ghostlink desktop UI

Reference: Outline Apps at ce518e8c058d4db9100ec27d15bc071a246a2274, its shared CSS and server-card/access-key-dialog source. Reference informs the flow and visual vocabulary. This is Ghostlink, with original UI markup and an original monoline app icon (a white ghost outline with a wavy hem and two eyes on a teal tile); no Outline logo or affiliation is implied. The mark's source is `ui/desktop/public/mark.svg`, with a copy at `ui/dashboard/public/mark.svg`; the build copies it into `apps/desktop/ui`, which is build output. `scripts/generate-icon.ps1` draws the same shape into `apps/desktop/src-tauri/icons/icon.png` and `icon.ico`. Inside the app the mark is monochrome and follows the finish.

Role: a quiet daily utility, viewed at laptop distance. Content capacity: up to 32 server cards with search, a compact active-connection panel, and key import dialog.

Look: since v0.7.0 the app shares the frosted-glass design of the server dashboard (the design rules in `ui/README.md`). Three finishes, each a set of CSS variables on `<html data-finish>`: Obsidian #090A0D, Titanium #111318 and Daylight #F2F4F8. Typography: SF Pro on Apple devices, then the bundled Plus Jakarta Sans; monospace (SF Mono, then the bundled JetBrains Mono) only for addresses, keys, ports and interface names. Frosted cards with 28 px corners, 24 px inner panels and pill-shaped controls over slow glass waves. Transitions of about 200-700 ms; with reduced motion the waves stand still and sheets open without animation.

Flows: add ss://, ssconf://, vless:// or vpn:// keys, or import a WireGuard or AmneziaWG .conf; list and search saved servers; connect, disconnect and switch; rename, details, remove; choose the default; split tunneling per server or for all servers; autoconnect preference; actual session status and counters; service diagnostics; Servers I run (your own Ghostlink servers, with the same views as the server dashboard); full screen; finish and background motion. No credentials in localStorage. Empty state and service-unavailable state contain no invented servers or connection statistics.
