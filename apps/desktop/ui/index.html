ACCESS KEYS

Keys

Share a key only with the person it belongs to. Anyone holding it can use this user's connection.

A shared group key is weak: anyone with the group key can pretend to be this server to other IPsec users, and its handshake can be guessed offline. Prefer a certificate or IKEv2.

The device installs these with a profile (.mobileconfig) and keeps the password or certificate in its Keychain.
